Server Connected Mode — Supabase Cloud Cases

Connects to the Supabase project configured below. Stores authenticated cloud cases, immutable revisions, and AP/LAT original images plus annotations. This is separate from local recovery and portable ZIP export.

Danger zone — Delete entire cloud case

Permanently removes the selected case, all its revisions, asset metadata, and associated Storage objects. The patient record is preserved. Permanent deletion is restricted to the designated disposable test project. The active project identity is checked in code; changing the URL field alone cannot unlock this operation.

LOCKED · Sign in to the designated disposable test project and select a synthetic case.
NOT CONNECTED · Enter the configured Supabase project URL and publishable key, then sign in.

Standalone Mode — Local Browser Storage

Use Standalone Mode only when you intentionally want browser-local recovery instead of a Supabase working copy. This does not change the application’s existing server communication.

R1142 · STANDALONE MODE INACTIVE · Sign in above for Connected Mode, or explicitly enable local-only recovery below.

Case File

Open or export a portable case ZIP containing CASE data, AP/LAT images, and annotations. Local autosave is recovery support; it is not a portable backup.

R887 — READY · Open a portable case ZIP or save a portable ZIP to device storage.
